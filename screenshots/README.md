# Required Screenshots for the Final PDF

After the pull request is merged, capture these screenshots and drop them
into this folder. They are listed in the order the rubric requires them
inside the final PDF.

| # | File name | What to capture |
|---|-----------|-----------------|
| 1 | `repo_homepage.png` | The repository home page on github.com showing the green folder list with the README rendered below |
| 2 | `readme.png` | The rendered README.md (scroll if needed so the project overview and structure are both visible) |
| 3 | `commits.png` | The commit history on the `main` branch after the merge — should show at least 3 commits clearly |
| 4 | `branch.png` | The branches view (`Insights → Network`, or the branches dropdown) showing `feature/parking-permit-system` |
| 5 | `pull_request.png` | The pull request page (Open or Closed) — title, description, commits, and Files changed are visible |
| 6 | `merged_pr.png` | The same pull request after it was merged (purple "Merged" badge and "Merged by ..." line visible) |
| 7 | `final_pdf_uploaded.png` | The repository view showing `final_report.pdf` in the file list |

## Tips

- On macOS, `Cmd + Shift + 4` then space-bar lets you capture a single window.
- Save the screenshots in `.png` format and name them exactly as in the table above so the final report can reference them by file name.
- If you also need a screenshot of the test cases (open in Google Sheets), save it as `test_cases_sheet.png` in this folder.
