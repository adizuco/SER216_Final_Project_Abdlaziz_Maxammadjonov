# Tools Used

| Tool | Purpose |
|------|---------|
| **Google Docs** | Drafting and formatting the final report content |
| **Google Sheets** | Building and editing the test case table (`tables/test_cases.csv` was imported into Sheets) |
| **diagrams.net** (draw.io) | Drawing the workflow diagram exported as `diagrams/workflow_diagram.png` |
| **GitHub** | Version control, branching, pull requests, and final submission |
| **Markdown** | Source format for `notes/`, `tables/`, and the report |

## Workflow

1. Drafted requirements and defect analysis in Google Docs, then copied to Markdown for the repo.
2. Built the test case table in Google Sheets and exported it as CSV (`test_cases.csv`).
3. Drew the workflow diagram in diagrams.net (Vehicle Registration → Permit Request → Zone Check → Permit Approval → Parking Verification) and exported it as PNG.
4. Compiled everything into a final PDF report.
5. Created a feature branch in GitHub, committed each deliverable separately, opened a pull request into `main`, and merged after review.
